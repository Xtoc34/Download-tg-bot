# Telegram Video Downloader Bot

Локальная версия бота, который принимает ссылку на YouTube, Instagram, TikTok и других сайтов, скачивает видео с помощью `yt-dlp` и отправляет его пользователю.

## 🔥 Новые возможности

- 🔒 **Система доступа по кодам** - только пользователи с кодом могут использовать бота
- 📊 **Статистика пользователей** - отслеживание активных пользователей и их запросов
- 👥 **Управление доступом** - создание и деактивация кодов доступа
- 📈 **Мониторинг** - подсчет количества пользователей и их активности

## Фичи

- ✅ Скачивание видео с YouTube, Instagram, TikTok и др.
- ✅ Выбор качества (144p, 240p, 360p, 720p, HD)
- ✅ Скачивание аудио из видео (m4a)
- ✅ SQLite история всех загрузок
- ✅ Обработка timeout-ошибок
- ✅ Поддержка ограничения размера файла (макс 50MB для Telegram)
- ✅ **Система кодов доступа** - ограничение доступа только для друзей
- ✅ **Статистика пользователей** - кто и как часто использует бота

## Требования

- Python 3.9+
- Установите зависимости:

```bash
pip install -r requirements.txt
```

## Переменные окружения

- `TELEGRAM_TOKEN` — токен вашего бота (получить у **BotFather** в Telegram)
- `ADMIN_IDS` — ID администраторов (ваш Telegram user ID, можно несколько через запятую)
- `YTDLP_COOKIES` — содержимое cookies.txt для YouTube, если видео требует вход или подтверждение
- `SUPPORT_BOT` — имя support-бота для ссылки в /help
- `WEBHOOK_URL` — полный HTTPS URL, если бот запускается в контейнере/на Railway и должен использовать webhook вместо polling

> **Важно:** Узнать свой Telegram ID можно через бота @userinfobot

> Не используйте чужие cookies из ненадёжных источников. Это ваш личный аккаунт, и лучше всего вставлять сюда собственные cookies при необходимости.

## Настройка системы доступа

### 1. Настройте администратора

В переменных окружения укажите свой Telegram user ID:

```bash
ADMIN_IDS=123456789
```

Можно указать несколько ID через запятую:

```bash
ADMIN_IDS=123456789,987654321,555555555
```

### 2. Создайте коды доступа

После запуска бота используйте команду `/create_code` (только для админов):

```
/create_code MYFRIENDCODE
```

Или бот автоматически создаст код по умолчанию при запуске.

### 3. Поделитесь кодом с друзьями

Отправьте друзьям код доступа. Они должны будут ввести его командой:

```
/code MYFRIENDCODE
```

### 4. Управляйте доступом

Администраторы могут:
- Просматривать статистику: `/stats`
- Создавать коды: `/create_code <название>`
- Смотреть все коды: `/list_codes`
- Деактивировать коды: `/deactivate_code <код>`


## История запросов

Бот хранит историю в `history.db` (SQLite) с информацией о:

- URL источника
- Выбранном качестве
- Статусе (done/failed)
- Названии скачанного файла
- Времени загрузки

Просмотреть историю: `/history` в чате с ботом

## Команды бота

### Для всех пользователей:
- `/start` — приветствие и информация о боте
- `/help` — как пользоваться
- `/history` — просмотреть историю загрузок
- `/language` — выбрать язык (русский/английский)
- `/code <код>` — ввести код доступа

### Только для администраторов:
- `/stats` — статистика бота (пользователи, запросы, активность)
- `/create_code [название]` — создать новый код доступа
- `/list_codes` — список всех кодов доступа
- `/deactivate_code <код>` — деактивировать код доступа

## Деплой на Railway.app (бесплатно, 24/7)

Railway.app позволяет запустить бота на бесплатном плане (5$ в месяц credits).

### Шаг 1: Подготовка к деплою

1. Убедитесь, что все файлы готовы:
   - `tg-bot-yt.py`
   - `requirements.txt`
   - `Procfile`
   - `runtime.txt`
   - `.gitignore`
   - `.env.example`

### Шаг 2: Git инициализация

```bash
git init
git add .
git commit -m "Initial commit"
```

### Шаг 3: Railway

1. Зайдите на https://railway.app
2. Нажмите **"New Project"** → **"Deploy from GitHub repo"** (или загрузите напрямую)
3. Выберите репо или загрузите файлы
4. Railway автоматически обнаружит `Procfile`
5. Добавьте переменные окружения:
   - Зайдите в **Variables** (⚙️)
   - Добавьте `TELEGRAM_TOKEN = ВАШ_ТОКЕН`
   - Добавьте `ADMIN_IDS = ВАШ_TELEGRAM_ID`
   - (опционально) добавьте `SUPPORT_BOT = support_bot_username`
   - (если нужны заблокированные видео) добавьте `YTDLP_COOKIES = <содержимое cookies.txt>`
6. Нажмите **Deploy** — бот запустится!

## Решение ошибок

### Ошибка "Timed out"

- Попробуйте 360p вместо HD
- Возможно, видео слишком большое или соединение медленное

### Ошибка "Видео недоступно"

- Видео может быть приватным, удалённым или по геоблоку

### Лимит 50MB

- Telegram имеет лимит на размер файлов
- Используйте 360p для больших видео

### Ошибка "Доступ ограничен"

- Пользователь должен ввести код доступа командой `/code <код>`
- Код можно получить у администратора бота

## База данных

Бот использует SQLite базу данных со следующими таблицами:

- `history` — история загрузок пользователей
- `user_settings` — настройки пользователей (язык, авторизация, статистика)
- `access_codes` — коды доступа
- `user_requests` — лог всех запросов пользователей
